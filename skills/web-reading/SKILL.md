---
name: web-reading
description: Fetches and compares specific web pages with Unfenced, returning readable content and source links.
---

Use Unfenced's `fetch_page` for a specific URL or `fetch_batch` for several URLs. Ground the answer in returned content and link each source. Report fetch errors directly. If the user requests page actions, use them only within the connected account's permissions. Do not claim to solve CAPTCHAs, read local files, or recursively crawl a domain.
